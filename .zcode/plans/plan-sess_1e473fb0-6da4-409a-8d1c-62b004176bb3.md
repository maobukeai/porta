# Porta 桌面端第二轮细化升级方案

延续第一轮"精细化打磨"的定位，聚焦四个已确认的薄弱点。移动端行为继续完全不变。

## A. 右侧面板桌面常驻标签栏（含终端保活）

**现状痛点**：SidePanel 的 activeTab 状态内部私有（SidePanel.tsx:2658），标签激活后只能"返回→再选卡片"或去顶部按钮切换；且切走 terminal 标签会卸载 SideTerminalView，**全部终端会话被销毁**（SideTerminalView.tsx:274-285）。

1. SidePanel 顶部新增桌面标签栏（复用 artifacts.css:110-160 已存在但未使用的 `zcode-sidepanel-tabbar/tab-list/tab-item` 样式）：标签 = 辅助对话 / 审查 / Git / 终端 / 子智能体目录（有会话时）；激活高亮、点击直接切换、右侧保留关闭面板按钮；空状态（选择器卡片）下也显示标签栏
2. **终端保活**：terminal 标签一旦打开过，用 `display:none` 包裹层保持挂载（仅终端做保活——它是唯一昂贵有状态视图；其余视图维持现有挂载/卸载）
3. 移动端（<1024px）CSS 隐藏标签栏，卡片选择器 + 返回按钮原样保留
4. desktop.css 补充 light 主题下的 tabbar 覆盖（现样式为暗色硬编码）
5. 更新 SidePanel.test.tsx 中因标签栏文字重复（"辅助对话"等）产生的歧义断言

## B. 会话内搜索 Ctrl+F（VS Code 式查找条）

**现状**：会话内无任何搜索能力。ChatPanel 已有全部数据（`messages` 状态）与滚动容器 ref。

1. 新组件 `ChatSearchOverlay.tsx`：ChatPanel 内渲染、`.chat-area-container` 右上角非模态查找条（该容器已是 position:relative）；对 user/assistant 消息做大小写不敏感匹配，显示"3/12"计数与上下文片段
2. 导航：Enter/F3 下一个、Shift+Enter/Shift+F3 上一个、Esc 关闭、点击结果跳转
3. 跳转与高亮：MessageBubble 根元素加 `data-step-index` / `data-optimistic-id` 稳定锚点（memo 比较器已含 stepIndex，零成本）；`scrollIntoView({block:"center"})` + 临时 `.search-flash` 描边动画 1.6s（消息体为 dangerouslySetInnerHTML 渲染，v1 不做文内 `<mark>` 注入，保持稳健）
4. App.tsx：Ctrl+F 分支（preventDefault 屏蔽浏览器原生查找、输入框聚焦时也可用）+ Esc 关闭链插入该项；通过自定义事件 `porta:open-chat-search` 通知 ChatPanel（与现有 `porta:cockpit-switch` 等事件模式一致）
5. 快捷键帮助面板登记 Ctrl+F；命令面板新增"在对话中查找"动作

## C. 输入区桌面打磨

**现状**：消息列宽为 `--chat-col`（780/1000px）但输入胶囊硬编码 `max-width: 840px` 共 5 处（input.css:14,23,490,579,605），桌面端输入区与消息列错位约 60px；左侧按钮组间距仅 4px。

1. input.css 五处 840px → `var(--chat-col, 840px)`，使输入区与消息列严格对齐（宽屏模式一并生效）
2. ChatInput.tsx 四处 `Math.min(el.scrollHeight, 200)` 高度上限改为桌面感知常量（≥1024px 取 260，其余 200），桌面可写更长内容
3. desktop.css：输入胶囊内边距加大、textarea 桌面 15px 字号、左组间距 4→8px、发送/停止按钮 32→34px、底部 safe-area 内边距改为固定值

## D. 命令面板增强

新增"停止当前任务"动作（仅会话运行中显示，复用 App 已有的 handleStop）与"在对话中查找"动作。
