# 智能体置顶任务栏与子智能体目录功能设计规范

## 1. 概述与问题背景

在 Antigravity 客户端中，当会话触发或派发子智能体（Subagents）时：
1. **当前问题**：若会话中仅有子智能体执行而未生成 `implementation_plan.md`，置顶任务栏（`PlanProgressCard`）因前置条件判定直接隐藏，导致无法感知智能体状态（例如会话 `1f6db4aa-0d91-4a45-a543-bf679812928d` 中 2 个智能体未显示）。
2. **需求目标**：
   - **置顶任务栏**：有智能体在执行（干活）时，展示智能体图标并带有**转圈加载标志**，点击可直接进入该智能体的执行页面；智能体执行结束后，自动收缩为紧凑折叠栏（`智能体` | `✔ 已结束 N >`）。
   - **子智能体目录**：在右侧面板与标签栏搜索中，提供 1:1 还原桌面端 IDE 的「子智能体目录」页面（含 `正在运行 · N`、`已结束 · N`、状态标签、相对时间及结果摘要），支持快速检索与一键跳转。

---

## 2. 架构与状态引擎设计

### 2.1 智能体状态解析与提取引擎 (`useSubagentViewer.ts`, `usePlanTracker.ts`)
- **JSON 序列化容错**：自动兼容 `args.Subagents` 为 JSON 字符串数组、原生 `invokeSubagent` 结构、以及 `tool_calls` 嵌套形式。
- **生命周期状态识别**：
  - `running`：步骤处于 `RUNNING` / `WAITING`，或父级 turn 尚未生成终止结果；
  - `completed`：成功返回且未报错；
  - `failed`：步骤为 `ERROR` 或包含 `errorMessage`。
- **数据联动**：
  - `extractSubagentStatsFromSteps` 与 `extractSubagentSessions` 深度对齐，计算真实的 `active`（运行中数量）与 `completed`（已结束数量）。

## 3. 组件交互与 UI 规范

### 3.1 右侧置顶任务栏 (`PlanProgressCard.tsx`)
- **渲染门禁优化**：
  - 放宽渲染条件：只要满足 `(hasPlan && total > 0)` OR `(subagentSessions.length > 0)` OR `(subagents.total > 0)` 即渲染任务栏。
- **分态显示逻辑**：
  - **有运行中智能体**：
    - 在任务栏中呈现高亮运行行，包含 `<IconBot>` + 旋转转圈动画徽标（`icon-spin` / 动态转圈环），显示角色与任务名称。
    - 点击该条目直接触发 `onSelectSubagent(s.id)` 进入该智能体的详情流。
  - **智能体全部结束**：
    - 自动收缩为底部紧凑栏（1:1 还原截图 1：`智能体` `✔ 已结束 N >`）。
    - 点击可展开气泡下拉弹窗快速选择，或点击打开「子智能体目录」。
  - **同时存在规划任务与智能体**：
    - 上半部分显示规划任务进度（已完成折叠/当前/待处理），下半部分显示智能体状态栏。

### 3.2 右侧面板与「子智能体目录」（1:1 还原截图 2）
- **「子智能体目录」独立视图 (`SubagentDirectoryView`)**：
  - **顶部标签栏**：显示 `[∨] [ :≡ 子智能体目录 x ] [+]`。
  - **标题**：`子智能体目录`。
  - **区块 1: `正在运行 · N`**：
    - 若 $N=0$：显示暗灰文案 `没有正在运行的子智能体`。
    - 若 $N>0$：显示运行中的智能体卡片（带旋转 Bot 图标、执行中标签、角色说明）。
  - **区块 2: `已结束 · N`**：
    - 列表展示已结束的智能体：
      - 左侧状态图标：`✔`（或失败 `✖`）
      - 标题：智能体角色名称（如 `修复单元测试缺陷`、`修复SQLite并发锁问题`）
      - 徽标：`已完成`（或 `执行失败`）
      - 相对时间：如 `1天`、`2小时`、`刚刚`
      - 摘要预览：自动提取智能体执行输出结果的关键 Markdown 摘要（截取前 120 字符），增强可读性。
  - **点击交互**：点击任意子智能体条目，立即打开该子智能体的完整对话流与执行步骤（`SubagentDetailViewer`）。

### 3.3 标签栏搜索下拉联动 (`vscode-editor-dropdown-menu`)
- 在右侧编辑器标签栏点击 `[∨]` 下拉按钮时：
  - 搜索框下方新增「子智能体」分区与「子智能体目录」快捷入口。
  - 在搜索框中输入关键字时，能同时匹配已打开文件、最近关闭文件与子智能体名称/角色。

---

## 4. 响应式与自适应支持
- **桌面端 / 宽屏**：右侧分栏中可自由在代码审查、Git、终端、「子智能体目录」与「子智能体详情」间平滑切换。
- **移动端 / 窄屏**：点击智能体或目录条目时，主界面以全屏模式无缝切换至子智能体页面，顶部配备清晰的“返回主对话”按钮与多智能体下拉切换器。
